Omniston — агрегатор ликвидности от STON.fi
Omniston — это децентрализованный протокол агрегации ликвидности, разработанный командой STON.fi специально для блокчейна TON. Его суть — собрать ликвидность из разных источников (DEX, RFQ-резолверы) и дать пользователю лучший курс обмена через единый интерфейс.



🏗 Архитектура и ключевые возможности
• Best Price Discovery — автоматически ищет оптимальный маршрут свапа, перебирая все доступные пулы ликвидности
• Мультиисточниковая агрегация — объединяет ликвидность AMM DEX (STON.fi и другие) и on-chain RFQ-резолверов
• Real-time котировки — цены обновляются в реальном времени через WebSocket
• Готовые транзакции — протокол отдаёт уже собранный объект транзакции, который остаётся только отправить
• Обработка ошибок — встроенные типы ошибок и механизмы восстановления



🔧 Способы интеграции
Способ                    | Для кого                                                         
--------------------------+------------------------------------------------------------------
**SDK (Node.js / React)** | Самый простой способ, рекомендуется для большинства разработчиков
**WebSocket (JSON-RPC)**  | Низкоуровневый API для кастомных интеграций                      
**gRPC (TLS)**            | Основной низкоуровневый API для бэкенда и резолверов

Демо-приложение доступно на omniston.ston.fi.



🌉 Кросс-чейн токены
На данный момент Omniston работает внутри экосистемы TON — агрегирует ликвидность TON-DEX'ов и RFQ-резолверов.

Кросс-чейн функционал (поддержка токенов из других сетей — Ethereum, BSC, и т.д.) находится в разработке. Команда активно работает над интеграцией мостовой ликвидности, которая позволит свапать активы между TON и другими блокчейнами напрямую через протокол. Конкретный список поддерживаемых кросс-чейн токенов пока не опубликован — стоит следить за обновлениями в документации.



💡 Юзкейсы
1. DEX-агрегация в кошельках и dApp — встроить свап с лучшим курсом без необходимости подключаться к каждому DEX отдельно. Один вызов — протокол сам найдёт лучший маршрут.
2. RFQ-торговля — запрос котировки у маркетмейкеров для крупных ордеров. Это даёт:
• Персональное ценообразование под объём
• Меньше проскальзывания на больших сделках
• Приватность — сделка согласовывается off-chain
3. Арбитраж — протокол автоматически выявляет разницу цен между пулами и может маршрутизировать ордер через самый выгодный путь.
4. Кросс-чейн свапы (в разработке) — после интеграции мостов пользователи смогут обменивать, например, ETH → TON-токен в одну транзакцию через единый интерфейс.
5. Реферальные комиссии — SDK позволяет разработчикам добавлять referral fee на каждый свап, монетизируя интеграцию.
6. Поставщики ликвидности — LP могут предоставлять ликвидность в пулы Omniston и получать вознаграждения.

Как покупать мемы из других сетей сейчас
Если тебе нужен мем из другой сети, пока работают классические пути:

1. Мост + DEX — переводишь TON через мост (TON Bridge, Multichain, Orbiter) в нужную сеть, затем свапаешь на локальном DEX (Uniswap, Raydium, и т.д.)
2. CEX — выводишь на биржу (Bybit, OKX), покупаешь мем, выводишь обратно
3. Кросс-чейн агрегаторы — 1inch, Jupiter (Solana), LI.FI — они уже умеют маршрутизировать между сетями



Что изменится с Omniston
Когда кросс-чейн функционал запустят, сценарий станет таким:
Выбираешь мем-токен из другой сети → Omniston сам находит маршрут (мост + DEX) → одна транзакция из TON-кошелька

Окружение и ключи

• AUTH_SECRET — обязателен в проде (Auth.js); для локалки есть dev-фолбек, но рекомендуется сгенерировать: npx auth secret.

• NEXT_PUBLIC_APP_URL — публичный URL приложения.
• NEXT_PUBLIC_TONAPI_BASE_URL — базовый URL TonAPI (публичный).
• TONAPI_API_KEY — серверный ключ TonAPI (НЕ NEXT_PUBLIC_*).
• NEXT_PUBLIC_WALLET_CONNECT_PROJECT_ID — WalletConnect (Reown) для EVM на странице Omnistone.
• NEXT_PUBLIC_OMNISTON_WS_URL — опционально (по умолчанию wss://omni-ws.ston.fi).
• В коде есть защита от утечки серверных ключей в клиент (TONAPI_API_KEY читается сервером; использование NEXT_PUBLIC_TONAPI_API_KEY помечено как устаревшее и только для девелопмента).

Slide 17: Cross-Chain Swap Flow
EN:
How Omnistone swaps work — step by step

1. Connect — User connects TON wallet (TON Connect) AND EVM wallet (Reown AppKit / WalletConnect)
2. Select — Choose source token on TON and destination token on EVM chain (e.g. TON → ETH on Ethereum)
3. Route — Omniston SDK queries wss://omni-ws.ston.fi for best route across liquidity sources
4. Confirm — User reviews swap details: rate, fees, estimated time, minimum received
5. Execute — TON transaction sent → Omniston routes → EVM tokens received in connected wallet
6. Track — Swap status tracked in real-time via WebSocket updates

No bridges. No wrapped tokens. Best price via aggregated liquidity.

RU:
Как работают свапы через Omnistone — пошагово

1. Подключение — Пользователь подключает TON-кошелёк (TON Connect) И EVM-кошелёк (Reown AppKit / WalletConnect)

ArrayTON — TON Wallet Analytics & Cross-Chain Swap Platform
ArrayTON — это open-source платформа для комплексной аналитики кошельков TON, отслеживания портфеля и кросс-чейн обмена. Проект объединяет данные блокчейна TON с возможностями децентрализованных свапов, предоставляя единый интерфейс для анализа, мониторинга и управления активами.
